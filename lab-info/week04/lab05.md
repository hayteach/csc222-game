# Lab 05 — Queue.remove(n)

Modify the Queue ADT to add a void method `remove(n)` that removes and discards the first `n` entries from a queue.

Modify the Queue implementation provided in class to include this new method and test it as part of the tester program.

You should use the code provided in the lecture class as your basis for this problem and just add this new method to the QueueADT and the proper implementation files.

Submit all files necessary to run your tester for review. Please place all of your files into a `.zip`, `.7z` or `.rar` archive and then upload that archive for grading.
