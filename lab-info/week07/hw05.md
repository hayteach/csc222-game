# Homework 05 – Linked-List Bag Template

This assignment is an individual programming task that extends your work from Homework 3.  You will implement and test a generic linked-list based Bag ADT.

## Objectives

- Reinforce your understanding of linked lists
- Practice template programming in C++
- Manage dynamic memory and pointer manipulation

## Description
The `LinkedBag` class (template) stores items in a singly linked list.  You will complete the class implementation by adding the following methods, many of which were started in Homework 3.

### Required operations

- `int getCurrentSize() const` — return the number of items currently stored.
- `bool isEmpty() const` — return `true` if the bag contains no items.
- `bool add(const ItemType& newEntry)` — add `newEntry` to the bag; return `true` on success.
- `bool remove(const ItemType& anEntry)` — remove one occurrence of `anEntry` from the bag;
  - if the item is found, decrement `itemCount` and unlink/delete the node before returning `true`.
  - if not found, return `false`.
- `void clear()` — remove all items from the bag, freeing memory.
- `bool contains(const ItemType& anEntry) const` — return `true` if `anEntry` appears in the bag; implement by traversing the list and setting a flag when found.
- `std::vector<ItemType> toVector() const` — return a vector with all items in the bag (used for display/debugging).

### Private data members

```cpp
Node<ItemType>* headPtr;    // pointer to first node in chain
int itemCount;              // current count of items
```

## Testing

Write a driver program that:

1. Instantiates a `LinkedBag<std::string>` (or `Bag` if you use a different name).
2. Exercises every member function with both positive and negative cases:
   - Add several strings, verify size and contents.
   - Remove existing and non-existing strings.
   - Check `contains` on present/absent values.
   - Call `clear` and ensure the bag is empty.
3. Print results to the console so a grader can see correct behavior.

## Submission

Place all source/header files for the `LinkedBag` template and your test program into a single `.zip`, `.7z`, or `.rar` archive.  Make sure the archive contains everything needed to compile and run the program, then submit the archive for grading.

> **Note:** A linked-list bag has the advantage of unbounded capacity, but the disadvantage of higher dynamic memory overhead compared to an array-based bag.
